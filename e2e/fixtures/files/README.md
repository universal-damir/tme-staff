# Test Fixture Files

Auto-generated on first run of `npm run test:onboarding`. Content:

- `tiny.png` — 68-byte 1x1 transparent PNG, reused for every image doc.
- `tiny.pdf` — minimal valid PDF, reused for every PDF doc.

Files are intentionally tiny because the test script bypasses AI validation —
any valid file is accepted by Supabase Storage + the submit endpoints.
